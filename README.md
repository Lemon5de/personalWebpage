## ✨ Features

- **Clean UI & Responsive Layout:** Optimized for both desktop and mobile viewports.
- **Project Showcase:** Highlights personal projects with direct links to live demos and repositories.
- **Fast & Lightweight:** Built with pure HTML, CSS, and Vanilla JavaScript—no heavy framework overhead.

- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting / Infrastructure:** Nginx on Oracle Cloud VPS
- **Version Control:** Git & GitHub
